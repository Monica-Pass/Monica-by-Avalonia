# Android 与 Avalonia 功能对齐

更新：2026-10-06。Android 源码为产品参照；下表记录实现范围，不能替代跨设备验收。

## 开发原则

- 核心业务尽量相同：相同条目类型、字段语义、保密规则与数据交换能力。
- 用户完成任务的路径尽量相近：创建、搜索、查看、复制、编辑、收藏、归档、恢复与同步。
- 桌面遵循键盘、窗口和主从布局习惯；不要求把手机页面逐像素复制到桌面。
- Android 专属系统集成按平台处理。桌面可以增加托盘、全局快捷键、自动输入、多标签等能力。
- 未知类型和高版本内容保留原数据，不能为了显示或编辑而静默降级。

## 当前范围与剩余工作

| 能力 | Avalonia 当前范围 | 继续对齐的工作 |
| --- | --- | --- |
| 密码库 | 多密码、网站、应用绑定、自定义字段、附件、分类、收藏、归档、回收站、历史 | 持续核对 Android 统一内容块、聚合条目与复杂字段的编辑和往返 |
| API Key | Android 标记字段、提供方网站、可选请求地址、加密保存 | 不参与登录自动输入；继续做跨端数据验收 |
| Wi-Fi | SSID、7 种加密类型、隐藏网络、二维码文本和图片导入、按需连接二维码、安全复制 | 企业认证、代理、静态 IP 与 MAC 设置保留原 JSON，专用编辑器和系统连接动作待补 |
| SSH 密钥 | 密码条目中的 SSH 数据保存与查看 | 对齐结构化密钥表单、生成和专用导入流程 |
| 通行密钥 | 本机记录列表、搜索、公开详情、确认删除；加密私钥事务存储、主密码变更重加密和会话取消保护；Windows WebAuthn 客户端 | 系统供应器、网站创建/登录桥、canonical MDBX 与跨端备份同步仍需实现；删除系统凭据的本地记录不等于删除系统密钥，Windows Hello 调用不等于系统级供应器 |
| 验证器 | TOTP/HOTP/Steam 格式验证码、二维码、导入导出、搜索、收藏 | Steam 验证码不代表完整 Steam 账户工作区；继续核对关联条目和二维码交换 |
| 安全笔记 | Markdown、多标签、附件、目录、草稿与本地保存 | 继续核对 Android 内容块与图片编辑；桌面保留多标签优势 |
| 钱包 | 银行卡、身份资料、证件、条码、账单地址等结构化类型 | 继续核对卡包排序、关联内容与跨端往返 |
| 安全分析与生成器 | 弱密码、重复、泄露检查、生成策略与历史 | 逐项核对 Android 的策略选项与风险处理路径 |
| 导入导出 | Monica JSON/CSV、Bitwarden JSON、KeePass、Aegis 等路径 | 明确每种格式不可承载的字段，继续补跨端真实样本 |
| 数据库与同步 | canonical MDBX、KeePass 工作区、Bitwarden 在线同步、WebDAV/OneDrive、加密本地备份恢复 | 继续核对真实多设备冲突、附件与完整内容保真；原生引擎版本兼容须独立验收 |
| 未知 MDBX 条目 | 只读摘要、授权查看、安全拒绝有损导出 | 未知类型不等于对应的业务功能已经实现 |
| Steam 账户工作区 | 通用验证器支持 Steam 码；未知 `steam-mafile` 可走只读查看 | 账户导入、登录确认、设备与交易功能属于业务差距，应分阶段实现 |
| 独立收藏与 Send 分享 | 当前桌面密码库有条目收藏 | 网页收藏与分享工作流需要独立实现，不能用条目收藏替代 |
| 语言与个性化 | 中英文、主题及桌面布局设置 | Android 其他语言与更细的页面个性化仍有差距 |

## 平台取舍

暂不移植 Android 输入法、无障碍服务、Shizuku、通知渠道与 Android Credential Provider。
桌面通过浏览器配对、全局搜索、安全剪贴板和可选自动输入提供对应任务入口。Windows
WebAuthn API 探测不能视为系统凭据提供器已经实现。相机扫描、Wi-Fi 系统连接、平台生物认证
等能力按各平台 API 单独评估；二维码图片导入是目前可用的桌面路径。

## Wi-Fi 对齐依据

实现参照 Android 的 `data/model/WifiData.kt`、`WifiEntryDetails.kt`、
`utils/WifiQrPayload.kt`、`WifiQrParser.kt` 与 `ui/components/WifiDetailContent.kt`。
桌面修改常用字段只改 `ssid/security/hiddenNetwork`，保留原始 JSON 中其余设置；未修改时
保留原元数据文本。开放网络允许空密码，个人网络密码保持原始空白字符，不拆成多条密码。
企业网络和未知加密类型不会伪装为个人网络生成连接二维码。二维码默认隐藏，关闭详情或锁定
时释放图片和载荷，图片导入完成后清零读入缓冲区，复制走安全剪贴板。

对应回归测试：`WifiQrCodecTests`、`WifiWorkflowTests`、`WifiQrImageTests` 与
`WifiWorkflowUiTests`。真实 Android 扫码连网与操作系统 Wi-Fi 连接仍需设备验证。
